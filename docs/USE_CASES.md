# Use cases

- Customer selects a service, future date and hourly slot, enters contact details and submits.
- UI disables resubmission while waiting; only HTTP 201 shows confirmation.
- An occupied slot produces a clear retry message and preserves form input.
- Invalid requests return 400 without inserting rows.
- Anonymous appointment listing is forbidden.
- Operator builds with Compose, or deploys a verified GHCR commit to Docker Desktop Kubernetes.
